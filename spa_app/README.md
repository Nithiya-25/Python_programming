🎮 Stone Paper Scissor - Flask Web App

A simple and interactive Stone Paper Scissor game built using Python Flask, HTML, and CSS.

---

🚀 Live Features

- 🪨 Stone vs Paper vs Scissor game logic
- 🤖 Computer random AI choice
- 🎯 Instant Win / Lose / Tie result
- 🎨 Clean UI with CSS styling
- 📱 Mobile + Desktop friendly
- ⚡ Fast Flask backend

---

🛠️ Tech Stack

- Python 🐍
- Flask 🌶️
- HTML5
- CSS3

▶️ How to Run

pip install flask
python app.py

Open in browser:

http://127.0.0.1:5000

---

🎮 Game Rules

- 🪨 Rock beats Scissor
- 📄 Paper beats Rock
- ✂️ Scissor beats Paper
